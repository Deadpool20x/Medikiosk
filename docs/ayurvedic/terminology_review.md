# MediKiosk Ayurvedic Terminology Review Ledger

> **Status: SOURCE-DERIVED, AWAITING CLINICIAN CONFIRMATION.**
>
> Every term used in `clinical_interview_spec_v1.md` is listed below and explicitly marked as one of:
>
> - **[CONFIRMED]** — clinician-confirmed (none yet; populated only after `clinician_questionnaire.md`
>   sign-off).
> - **[SOURCE]** — source-derived but **awaiting clinician confirmation** (rooted in classical text or
>   peer-reviewed literature, cited below).
> - **[UNRESOLVED]** — source conflicts / correlation is contested or uncertain; must be resolved by a
>   clinician before it may be used with authority.
>
> The system is **not** to be presented as Ayurvedic-clinically validated until a clinician sign-off
> moves `[SOURCE]`/`[UNRESOLVED]` items to `[CONFIRMED]` (or amends this ledger).
>
> Terminology may appear in code today (Phase 1 deterministic triggers) but that is provisional
> pilot intake mapping, **not** clinical validation. See governance note at the bottom.

## 4. Governance & code-alignment notes

1. **Phase 1 code already contains classical tokens** in `backend/rules/adaptive_interview.py`
   (trigger lists and evidence_source citations: Charaka Chikitsa Sthana Vatavyadhi, Kasa/Shwasa,
   Grahani/Amlapitta). Those are **provisional pilot intake mappings**, not clinical validation.
2. **Changing status flow**: `[SOURCE]` → `[CONFIRMED]` (or amended/rejected) only via the
   `clinician_questionnaire.md` sign-off. The source `evidence_source` strings may be updated after
   sign-off to cite the reviewer.
3. **[UNRESOLVED] items must not be used as authoritative labels** in patient- or doctor-facing output
   until resolved: amlapitta/GERD, sandhigata vata/OA, grudhrasi/sciatica, vatarakta/gout,
   ksaaya/TB, tamaka/asthma, agnimandya/dyspepsia, grahani/malabsorption.
4. **No term implies disease diagnosis.** The kiosk asks for *features* (e.g., "dry cough with little
   phlegm, worse at night") — the dosha/subtype *labels* stay physician-side unless a clinician marks
   them patient-usable in §5 of the questionnaire.
5. This ledger is the single source of truth for which terms may appear in summary output. Update it,
   not the code, when clinical confirmation changes a standing.
