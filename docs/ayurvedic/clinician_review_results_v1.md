# MediKiosk Ayurvedic Clinician Review Results — v1 (Packet & Register)

> **Status: REVIEW PREPARATION — awaiting clinician sign-off.**
>
> This file is the **working packet** for a real Ayurvedic clinician meeting. It presents every
> proposed item from `clinical_interview_spec_v1.md` in a fill-in table, one per pilot domain, plus a
> cross-domain table. During the meeting the clinician fills decision columns; after the meeting the
> resolved outcomes are transferred into the four registers in §6.
>
> **Rules honored:**
> - Nothing is marked CONFIRMED here. **CONFIRMED requires an explicit clinician decision** recorded
>   in the tables below and reflected back into `terminology_review.md` (which this packet is
>   intentionally paired with).
> - The existing provisional specification (`clinical_interview_spec_v1.md`) is **preserved
>   unchanged**; this packet only *prepares* its review.
> - No production code changes.
>
> How to fill a row: mark **Keep / Modify / Remove**, add **Clinician rationale** (one line), write
> **Final wording** if you change the wording, mark **Mandatory / Optional** (must-not-skip vs may be
> deferred to the doctor's "not gathered" summary), sign with **initials + date**.
